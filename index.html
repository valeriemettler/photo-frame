Checking…

1. Dropbox App key

From dropbox.com/developers/apps → your app → Settings tab → "App key". It is safe to paste here.

2. Connect

Tap Connect. Dropbox opens and shows you a code. Copy that code, come back here, paste it below, and tap Finish.

Tap here to open Dropbox →

If Dropbox did not open by itself, tap the blue link above. Approve it, copy the code Dropbox shows you, then come back and paste it below.

3. Which folder

Leave this empty to use the app's own folder (Dropbox → Apps → your app name). Or type a folder path such as /Photo Frame.
